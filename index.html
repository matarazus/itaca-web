POR QUE ÍTACA?
Porque toda jornada merece um lugar para voltar.

Ítaca é mais que uma ilha grega. É uma imagem que atravessa séculos de literatura: o desejo de voltar, o valor do caminho e a transformação que acontece entre a partida e a chegada.

Perguntas frequentes

Antes da primeira palavra.

Algumas respostas para você conhecer o Ítaca antes de começar.

Posso experimentar o Ítaca agora? +

Sim. Clique em “Experimentar beta no navegador” para abrir o editor, sem instalar nada nem criar conta. As versões para Mac e Windows ainda estão em desenvolvimento. Por ser beta, faça backups regulares dos seus livros em JSON.

O Ítaca funciona sem internet? +

Para acessar a versão beta hospedada, é preciso conexão com a internet na primeira abertura. Depois que a página carrega, a escrita e o armazenamento podem funcionar localmente; o modo offline não é garantido se o navegador limpar os arquivos do site. Os aplicativos para desktop estão em desenvolvimento.

Onde ficam meus livros? +

Na versão HTML, os dados são salvos no armazenamento local do navegador, quando permitido. Faça backups em JSON regularmente. Na versão de desktop, o armazenamento será gerenciado pelo próprio aplicativo.

Posso exportar o que escrevi? +

Sim. O Ítaca permite exportar capítulos ou livros completos em PDF, Word (.docx) e texto simples (.txt).

Haverá versão para Windows? +

Sim. As versões Windows e Mac estão em desenvolvimento e ainda não têm download público disponível. Enquanto isso, você pode testar a beta no navegador.
